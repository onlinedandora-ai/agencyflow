# AgencyFlow Web App

Next.js 16 frontend and API routes for AgencyFlow.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Build

```bash
npm run build
```

## Production Deployment

This app can be deployed on Firebase App Hosting, Google Cloud Run, Docker, or any Node.js container environment.
