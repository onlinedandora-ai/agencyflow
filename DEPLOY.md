## 2. Deploy API on Render

1. Open https://dashboard.render.com/select-repo?type=blueprint
2. Connect **vaitahavya/agencyflow** → apply `render.yaml`
3. Set these env vars on **agencyflow-api**:

| Variable | Value |
|----------|-------|
| `DATABASE_URL` | Pooler URL from `apps/api/.env` — **no quotes** |
| `DIRECT_URL` | Session pooler URL — **no quotes** |
| `WEB_ORIGIN` | `https://YOUR-APP.vercel.app` (set after step 3) |
| `JWT_SECRET` | Auto-generated by Render (or use a long random string) |
| `RAZORPAY_KEY_ID` | From [Razorpay Dashboard](https://dashboard.razorpay.com/app/keys) → API Keys |
| `RAZORPAY_KEY_SECRET` | Same page (keep secret; server-only) |

Do **not** set `PORT` manually — Render assigns it automatically.

**Common mistakes:**

- Pasting `"postgresql://..."` with quotes — paste the raw URL only (no surrounding `"` or `'`).
- Password contains `?`, `@`, `#`, `%`, or `&` — those must be **URL-encoded** in the connection string (e.g. `?` → `%3F`). Otherwise Prisma truncates the password and you get `P1000 Authentication failed`.

Encode before pasting into Render (run locally):

```bash
python3 - <<'PY'
from urllib.parse import quote
password = input('DB password: ').rstrip('\n')
print(quote(password, safe=''))
PY
```

Then use the encoded string as the password segment in both URLs.

4. Wait for deploy → test your **real** Render URL (dashboard → agencyflow-api → copy URL):  
   `https://agencyflow-api-yrzo.onrender.com/health`

## 3. Web on Vercel (already connected)

Git auto-deploy is **already configured**. After `git push origin main`, Vercel builds automatically.

**Production project:** `agencyflow-api` → https://agencyflow-api.vercel.app

| Setting | Value |
|---------|-------|
| Root Directory | `apps/web` |
| Production branch | `main` |
| Install | `cd ../.. && npm install` (see `apps/web/vercel.json` for `--include=optional`) |
| Build | `cd ../.. && npm run build --workspace=apps/web` |

**Required env var** (Vercel → agencyflow-api → Settings → Environment Variables):

```
NEXT_PUBLIC_API_URL=https://agencyflow-api-yrzo.onrender.com
```

**First-time setup only** (if reconnecting):

1. https://vercel.com/new → Import **vaitahavya/agencyflow**
2. Project name: `agencyflow-api`
3. **Root Directory:** `apps/web`
4. Add `NEXT_PUBLIC_API_URL` above
5. Deploy

To reconnect Git from CLI:

```bash
cd apps/web
npx vercel link --project agencyflow-api
npx vercel git connect https://github.com/vaitahavya/agencyflow
```

## CLI shortcuts (emergency / local only)

Use **Git push** for normal deploys. CLI is for debugging or when Git hooks fail.

```bash

npx vercel --prod

# Test API Docker image locally
```
